# R Programming: Data Analysis, Visualization & Machine Learning

## Overview
This repository contains my hands-on practice in R programming, covering data manipulation, exploratory data analysis (EDA), statistical analysis, data visualization, and supervised machine learning. The exercises involve working with different datasets to develop practical skills in data analysis, statistical modelling, and predictive analytics.

## Topics Covered

- **R Programming Fundamentals:** Variables, vectors, data types, matrices, arrays, lists, and data frames.
- **Data Manipulation:** Data selection, filtering, transformation, sorting, and summarization using `dplyr`.
- **Exploratory Data Analysis (EDA):** Data exploration, descriptive statistics, and identifying patterns and relationships.
- **Data Visualization:** Histograms, scatter plots, bar plots, box plots, and frequency polygons using Base R and `ggplot2`.
- **Statistical Analysis:** Descriptive statistics and regression analysis.
- **Supervised Machine Learning:**
  - Linear Regression
  - Multiple Linear Regression
  - Support Vector Machine (SVM)
  - Training and Testing Data Splitting
  - Model Prediction and Evaluation
- **Model Evaluation:** Actual vs. predicted values, prediction errors, and Root Mean Squared Error (RMSE).

## Libraries Used
- `ggplot2` – Data visualization
- `dplyr` – Data manipulation
- `caTools` – Training and testing data splitting
- `hflights` – Flight dataset analysis
- `scales` – Visualization scale formatting

## Datasets
- Iris Dataset
- House Sales Dataset
- Housing Price Dataset
- hflights Dataset
- mtcars Dataset
- Salary Dataset

## Objective
To develop practical skills in R programming, data analytics, statistical modelling, and supervised machine learning through hands-on exercises and real-world datasets.

**Tools:** R, RStudio, ggplot2, dplyr

**Focus:** Data Analytics | Statistical Modelling | Supervised Machine Learning
